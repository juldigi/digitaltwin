# OFFSET 5 — Factory Digital Twin

Fondasi aplikasi web: frontend GitHub Pages, backend Cloudflare Workers + D1, Vanilla JavaScript dan Three.js.

Pemulihan V56 mencakup 41 mesin, tiga digital twin utama (Offset 5, Offset 10, dan APM 2), taxonomy enam tingkat, simulasi proses, tampilan pabrik berbasis DXF, UI responsif, serta fallback WebGL.

## Menjalankan

```sh
npm ci
npm test
npm run build
npm run dev
```
