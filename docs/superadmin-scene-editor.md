# Superadmin scene editor

Configure a distinct `SUPERADMIN_TOKEN` secret on the Cloudflare Worker. Its bearer token grants existing administrator operations and the scene editor; the ordinary admin token cannot write scene overrides. Connect using the Superadmin token, then open **Pengaturan → Editor Scene 3D**.

The editor stores object transforms, visibility, soft deletion, lock state, duplication references, and simple added box/cylinder objects in the existing D1 `twin_state` row. It requires no additional migration. Every save preserves the preceding override map as a revision, up to ten revisions. The scene endpoint checks `If-Match` against the state revision. The editor has numeric transform inputs, a Three.js gizmo, object search, 10 cm position and 5° rotation snap, mobile nudge buttons, temporary isolation, original/draft preview, focus, hide/restore, soft delete/restore, lock/unlock, duplicate, floor grounding, alignment to a factory asset, dimensions, asset envelope overlap warnings, JSON import/export, undo/redo for the current editing session, and a selectable server revision history. Factory and current machine component scopes are separate. Closing without saving discards the draft. The Worker limits each revision to 500 changed objects.

`wall:` IDs use source handles and source segment coordinates; `part:` IDs use the machine key and taxonomy node ID where unique; `asset:` IDs use machine IDs. These survive unrelated sibling insertions. Other `node:` and `machine:` IDs are structural paths. After a code update changes their hierarchy, paths can point to different objects; the editor stores a fingerprint and skips a mismatch instead of moving the wrong geometry. Such overrides are reported as stale and should be reviewed. `copy:` records refer to source objects and are reconstructed each time the scene loads. Copies of assemblies with more than 300 meshes are blocked to protect phone performance. `new:` records create basic box/cylinder shapes. Hidden and deleted objects remain in source geometry and can be restored. Editing an active process component can still affect its animation; stop simulation and verify the affected machine after saving.

Source wall segments are grouped with their plinth, girts, glazing, joints, and flashing. Endpoint coordinates move and rescale the entire segment, but doors and openings are separate objects and need visual review after moving walls. The original source wall geometry is preserved in the code and D1 stores only its override. Basic added shapes are placeholders for field corrections, not photo-verified assets; arbitrary mesh topology cannot be edited in the browser. Collision warnings use asset axis-aligned bounding boxes and can include intended intersections; small part collisions are not exhaustively detected. Superadmin access is enforced on the Worker, not only by hiding the menu.
